# 长程演进路线图 (Roadmap)

本项目按“先通用化重构并真实可用 → 离线与传播能力完备 → 开源推广与可选双屏协同”的节奏分 4 个里程碑推进，严禁一步登天做重后端平台。

## M0 · 底座搭建与交接（当前已完成）
- [x] 建立独立工程仓库，与「半亩 / Bothy」彻底解耦
- [x] 隔离并保存本地 `reference/v0-prototype.html`（不进 Git）
- [x] 完成产品愿景、技术架构、长程路线图与独立京东云静态部署脚本

## M1 · 通用化重构 MVP（下个会话核心目标）
**目标**：用干净模块化架构彻底替代 `v0` 单文件原型，消除所有个人病例硬编码，补齐配置器与医护交接卡。
- [ ] 初始化 `Vite + React 19 + TypeScript + Vitest` 工程脚手架与移动端单手优先 Design Tokens
- [ ] 建立解耦的循证医学知识库（支持 `自然临产` / `计划催产` / `择期剖宫产` 三主线 + `初产/经产` + 常见风险标签动态挂载）
- [ ] 完成 30 秒「孕产画像配置器」及 2–3 个开箱即用预设（首次访问不配置也能直接体验完整功能）
- [ ] 重构五大核心功能视图：
  1. **陪产主线**（按画像裁剪的阶段进度、待办、医生提问卡、折叠知识块）
  2. **宫缩计时器**（单手盲操大按钮、5-1-1 / 3-1-1 动态判读、异常持续收紧告警）
  3. **医护交接卡**（1 屏高对比度实时战报：破水时间/性状、近 1 小时宫缩频次、内检记录、风险标签）
  4. **高危红线页**（1 秒呼出、呼救第一句话术模板）
  5. **给她看视角**（呼吸节拍器可调吸呼比 + 柔和夜视安抚屏）
- [ ] 领域逻辑全量 Vitest 单测通过 + 移动端视口（`390x844`）无报错通过
- [ ] 部署到京东云 `/opt/apps/sites/<slug>/` 实机验证（支持公开体验路由）

## M2 · 极端环境打磨与产后收口（可推广质量门槛）
**目标**：确保在医院地下室/无信号产房 100% 稳定，并形成可留念、可分享的传播闭环。
- [ ] 接入 `vite-plugin-pwa`：Service Worker 全量离线缓存、支持添加到手机桌面图标
- [ ] Wake Lock API 屏幕常亮与异常恢复提示（兼容 iOS Safari / Android Chrome）
- [ ] 产程关键事件打点器 + **产后「迎新时间线纪念卡 / Markdown 复盘」一键导出**（可导入「半亩」或直接保存图片）
- [ ] 医学内容出处注记（ACOG / 中华医学会指南参考索引）与无障碍对比度审计

## M3 · 公开推广与社区准备
- [ ] 增加轻量落地说明页 / 分享卡片（清晰传达零广告、零账号、断网可用核心卖点）
- [ ] 整理医学内容审校清单（邀请产科医护/有过陪产经验的用户共同复核措辞）
- [ ] 发布开源仓库 README、贡献指南（如何 PR 补充各地区医院差异提示）与实战故事文章

## M4 · 可选增强：伴侣双屏实时协同（按需触发，非必选）
- [ ] 若真实用户明确反馈“想自己手机看呼吸、丈夫手机按计时”，基于京东云 `/opt/apps/services/`（`:33xx` 端口 + `quickapp@.service`）增加极简临时房间码 WebSocket 同步服务，断网自动退回本地模式，不设长期账号库。
