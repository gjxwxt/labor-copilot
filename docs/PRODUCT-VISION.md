# 产品愿景与可推广性深度思考 (Product Vision)

## 1. 先承认 v0 为什么成功，再看清它为什么“不能推广”

`v0` 原型在真实陪产场景下击中了一个被主流母婴 App 严重忽视的痛点：
- 市面上的孕育 App（宝宝树、美柚等）充满**广告、社区焦虑、电商推销、复杂菜单**；真正进医院待产室那 10–30 个小时里，陪产家属（往往是第一次进产房、睡眠不足、高度紧张的爸爸）根本不需要看科普长文，他们只需要一个**“当下这一步我该干嘛、什么时候按铃叫医生、怎么帮她呼吸和记录宫缩”的副驾驶**。

但 `v0` 作为“别人的 agent 临时写的个人救急页”，存在 **5 个决定性缺陷**，使它目前只能当一次性 Demo，不能成为可推广的好产品：

1. **个人病例硬编码，无法服务第二个人**
   - 原型把“40+2 催产”“双顶径 9.8 / 8 斤”“胆汁酸偏高”等个人医疗事实直接写死进阶段清单和提问卡，既暴露隐私，对自然临产、经产妇、早产/糖妈等人群也完全不适用。
2. **缺少「1 分钟临床交接战报（Doctor/Nurse Handover Card）」**
   - 原型提醒“把手机给护士看”，但实际「宫缩」页只展示最近几条时间和粗略间隔。急诊/待产室医生护士最希望 3 秒看清：**是否破水及几点破水/羊水性状、过去 1 小时平均宫缩间隔与持续时长、上次内检几指、关键风险标签（如 GBS+/GDM/巨大儿评估/无痛意愿）**。
3. **单文件 1385 行泥球，无法持续迭代与内容审核**
   - 医学文案、状态流转、SVG 图标、样式全部混在一起，既没法针对不同手机屏幕、暗黑夜视做精细打磨，也没法让医学背景贡献者单独审校文案。
4. **缺少真正的弱网/断网 PWA 保障与产房环境细节**
   - 很多医院待产室/产房信号极差，甚至地下室手术室外无信号。纯靠在线页面刷新一次可能直接白屏。必须做成离线缓存优先的 PWA + 屏幕常亮锁定（Wake Lock 优雅降级）+ 单手大热区防误触。
5. **缺少“产后收口与可分享传播钩子”**
   - 生完宝宝、观察完产后 2 小时之后，工具就结束了。如果能**一键生成一份干净的「迎新时间线纪念图 / Markdown 战报」**（几点入院、打无痛、开全、宝宝出生时刻），既是给产妇和家人的珍贵纪念，也是最克制、最有口碑传播力的分享入口（不靠拉人头和弹窗广告）。

## 2. 产品定位与核心原则

- **一句话定位**：**“产房里的无广告、零登录副驾驶——让陪产者少慌 80%，把最关键的观察和提问稳稳托住。”**
- **核心用户**：
  1. **主用户（陪产者 / 准爸爸 / 家人）**：全程掌控时间线、记录宫缩、看提醒、向医生精准发问、在红线出现时果断按铃。
  2. **伴随视角（准妈妈）**：极简、温和、超大字号的「给她看」界面（呼吸节拍器 + 当下安抚语 + 不制造额外焦虑）。
  3. **次级受益者（护士 / 助产士 / 医生）**：只看一屏清晰结构化的「临床交接卡」。
- **五大设计原则**：
  1. **30 秒配置，千人千面，但克制选项**：首次打开只填 3–4 个核心参数（胎次、预计分娩/发动方式、特殊医学关注标签、医院条件），动态组装专属路线图与提问卡；**随时支持跳过，用“通用待产预设”零门槛进入**。
  2. **极简、高压友好（Stress-Proof UI）**：少字短句、动词开头、单手拇指区完成 90% 操作；夜晚病房低亮度护眼，红色仅保留给真正需要按铃的「医疗红线」。
  3. **隐私即默认（Local-First & Zero-Account）**：强制无注册可用。医疗情况与宫缩/时间线日志全部落本地存储，支持一键导出与一键销毁。
  4. **循证边界透明**：每条医学判读（如 `5-1-1` 规律宫缩法则、破水防脐带脱垂平卧垫臀原则、产后 2 小时出血观察）在数据层标注依据来源，同时保持克制且醒目的医疗免责边界——**“工具辅助观察，决策永远交由医生与助产士。”**
  5. **静态为王，渐进增强**：核心能力 100% 离线静态运行；“双机同步”等重网络能力放在后期作为**可选插件/房间码模式**，绝不让网络故障拖垮核心体验。

## 3. 推广路径思考（先真实好用，再口碑扩散）

1. **先打磨出公开版 MVP + 2 套真实预设演示（无需填写也能体验）**：让准爸妈点开链接 10 秒看懂价值。
2. **真实体验闭环与产科专业人士审校**：邀请有过陪产经历的朋友、产科医生/助产士/Doula 审校文案边界与红线措辞，消除误导风险。
3. **开源 + 场景故事传播**：
   - GitHub 开源（清晰架构 + 医学知识 JSON 可 PR 共建不同城市医院差异/经验提示）；
   - 以“我用 AI 重构了一个零广告、断网也能用的产房陪产副驾驶”做技术/生活复盘（可在「半亩 / Bothy」沉淀长文）；
   - 提供干净的私有部署指南（1 个静态目录就能跑），甚至医院孕妇学校或母婴博主也可直接引用或定制。
